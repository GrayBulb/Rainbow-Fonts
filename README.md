# Rainbow-Fonts
Chrome exenstion that makes fonts rainbow

To set custom speed, go to the folder of the chrome extension, open rainbowFonts.js in notepad. Find ```SPEED = 100``` and change it to whatever number.



# Guide to Install
1. Download or clone the extension folder to your computer.
2. Open Chrome and go to ```chrome://extensions/```
3. Turn on **Developer mode** (top right toggle).
4. Click **Load unpacked**.
5. Select the folder where the extension is located.
6. The extension should now appear in your toolbar or extension list.
